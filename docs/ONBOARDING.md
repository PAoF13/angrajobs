# Onboarding técnico

1. Instale Node.js 24 LTS e Git.
2. Clone o repositório.
3. Copie `.env.example` para `.env.local`.
4. Use credenciais do Supabase de staging, nunca produção para desenvolvimento.
5. Rode as migrations em staging.
6. Instale dependências e gere/versione `package-lock.json`.
7. Execute `npm run lint`, `npm run typecheck`, `npm test` e `npm run build`.
8. Rode `npm run dev` e valide os fluxos candidato e empresa.
